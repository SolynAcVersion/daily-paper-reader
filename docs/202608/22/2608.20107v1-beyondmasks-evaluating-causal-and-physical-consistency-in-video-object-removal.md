## 摘要
生成视频模型的最新进展显著提升了视频对象移除的视觉真实感，然而评估协议仍聚焦于掩码区域保真度，将移除视为局部修补。在真实场景中，对象移除是一种因果干预：消除一个对象还需要移除其引发的物理效应，如阴影、反射、光照变化、半透明效果和动态痕迹。现有基准缺乏对齐的干净参考，或局限于简化的合成设置，无法系统评估因果一致性。我们提出了BeyondMasks，一个用于因果一致视频对象移除的成对基准，包含时间对齐的合成和真实世界视频对，并带有干净背景参考。该数据集涵盖多样的光度、几何、体积和动态交互，支持基于掩码和指令驱动的编辑。我们进一步提出了CORE，一种基于结构化视觉语言模型的评估协议，联合衡量对象消失和余效一致性，与现有指标相比更接近人类判断。对最先进方法的基准测试揭示了，尽管掩码区域保真度高，但在移除次级物理效应方面存在系统性失败，暴露了视觉合理性与因果正确性之间的差距。BeyondMasks将视频对象移除重新定义为因果场景一致性而非局部重建，并为其评估提供了统一框架。

## Abstract
Recent advances in generative video models have significantly improved visual realism in video object removal, yet evaluation protocols still focus on masked region fidelity, treating removal as local inpainting. In real scenes, object removal is a causal intervention: eliminating an object also requires removing its induced physical effects, such as shadows, reflections, illumination changes, translucency, and dynamic traces. Existing benchmarks lack aligned clean references or remain limited to simplified synthetic settings, preventing systematic evaluation of causal consistency. We introduce BeyondMasks, a paired benchmark for causally consistent video object removal, consisting of temporally aligned synthetic and real world video pairs with clean background references. The dataset spans diverse photometric, geometric, volumetric, and dynamic interactions, and supports both mask based and instruction driven editing. We further propose CORE, a structured vision language model based evaluation protocol that jointly measures object disappearance and after effect consistency, aligning more closely with human judgments than existing metrics. Benchmarking state of the art methods reveals systematic failures in removing secondary physical effects despite high masked region fidelity, exposing a gap between visual plausibility and causal correctness. BeyondMasks reframes video object removal as causal scene consistency rather than local reconstruction and provides a unified framework for its evaluation.

## 1. 核心问题与整体含义

- **研究动机**：近年来生成式视频模型极大提升了视频对象移除的视觉真实感，但现有评估协议仍将移除任务视为“掩码区域内的局部修补”，只关注被掩码区域的像素重建保真度（如 PSNR、SSIM、LPIPS）。
- **关键洞见**：真实场景中，对象移除是一种“因果干预”（causal intervention）。对象不仅占据像素，还会通过与环境的物理交互产生阴影、反射、光照变化、半透明透射、蒸汽/散射、水波/尘埃等动态痕迹。移除对象后必须同时移除这些“物理余效”（after-effects），场景才算真正恢复。
- **现有不足**：DAVIS、YouTube-VOS 等常用数据集没有成对的干净背景参考；HQVI 虽有配对数据，但通过 alpha 合成构建，忽略了次级环境效应；ROSE-Bench 引入合成配对数据，但交互类型有限，且不支持指令驱动编辑。
- **论文目标**：将视频对象移除重新定义为“因果场景一致性”问题，并提出 BeyondMasks 基准与 CORE 评估协议，以系统衡量对象消失和物理余效消除的情况，揭示视觉合理性与因果正确性之间的差距。

## 2. 方法论

### 2.1 因果形式化框架
- 将每一帧视为对场景状态 \(S_t\) 和对象存在 \(O\) 的渲染结果：\(V_t = R(S_t, O)\)。
- 移除对象等价于对 \(O\) 施加干预，目标是恢复“反事实”渲染结果 \(V_t^{bg} = R(S_t, \emptyset)\)，即对象从未出现时的场景状态。
- 该公式强调：对象不仅直接影响自身像素，还通过改变光照、反射、表面形变等间接改变场景状态 \(S_t\)，因此不能仅靠掩码内修复完成。

### 2.2 BeyondMasks 数据集构建
- **合成子集（90 个视频）**：
  - 使用 Veo 3 先生成不含对象的背景视频，再通过受控编辑将对象插入同一场景，得到时间对齐的对象存在视频。
  - 支持阴影、反射、光照变化、半透明等物理一致的交互。
- **真实子集（90 个视频）**：
  - 用三脚架固定相机，先拍摄含对象视频，再在相同机位与设置下拍摄移除对象后的背景视频。
  - 自然呈现真实纹理、光照变化与交互模式。
- **掩码标注**：
  - 采用 SAM2 交互式分割 + CoTracker 3 时间传播的半自动管线，并由第二标注人交叉审核。
  - 掩码**只覆盖对象本体**，**明确排除**阴影、反射等余效，迫使模型通过物理推理而非显式监督来消除余效。
- **余效分类学**：阴影、反射、半透明效应、蒸汽/散射、因果物理效应（如脚印、水波）、光源效应、无显式余效七类。
- **指令提示**：为每个样本提供经过验证的文本提示，支持掩码驱动和指令驱动两种编辑范式。

### 2.3 CORE 评估协议
- CORE（Causal Object Removal Evaluation）基于预训练视觉语言模型（VLM，采用 Gemini 3.1），输入三个视频：含对象输入 \(V\)、GT 干净背景 \(V^{bg}\)、模型输出 \(\hat{V}^{bg}\)。
- 结构化提示引导 VLM 完成四步推理：
  1. 在输入视频中定位目标对象及其余效；
  2. 从 GT 中推断期望的干净背景；
  3. 将输出与 GT 比较，判断背景重建是否自然、是否出现幻觉内容；
  4. 将残留错误分类为“对象相关”或“余效相关”。
- 输出两个 1–5 分指标：
  - **CORE-OS（ObjectScore）**：目标对象是否完全移除、背景恢复是否自然；
  - **CORE-AES（AfterEffectScore）**：阴影、反射、光照变化等物理余效是否被消除。
- 通过让 VLM 基于对齐参考进行结构化比较，CORE 将评估从“观察真实性”升级为“干预正确性验证”。

## 3. 实验设计

### 3.1 基准与数据集
- **BeyondMasks**：共 180 个时间对齐的配对视频（90 合成 + 90 真实），每对包含含对象视频、干净背景参考、逐帧对象掩码和指令提示。
- 类别分布不均衡，更接近自然场景：阴影 127、反射 61、半透明 46、因果物理 37、光源 38、蒸汽 20、无余效 6。

### 3.2 对比方法
主实验共评估 10 种方法，涵盖三类范式：
- **掩码驱动（M）**：ProPainter、DiffuEraser、MiniMax、ROSE、OmnimatteZero、EffectErase；
- **文本驱动（T）**：Lucy Edit；
- **混合（T+M）**：VACE、CoCoCo、Generative Omnimatte。
补充实验中还加入图像级移除方法 OmniPaint 和 ObjectClear（逐帧处理）。

### 3.3 评估协议

## 6. 主要结论与发现

- **像素指标与因果正确性脱节**：DiffuEraser 取得最高 PSNR/SSIM 和最低 LPIPS，但其 CORE-AES 明显偏低；ROSE 的像素指标中等但 CORE-OS 最高。像素保真并不能反映对象及其余效是否被真正移除。
- **次级物理效应是主要失败点**：大多数方法能较好移除对象本体，但普遍残留阴影、反射、光照变化等；蒸汽/散射和动态交互（脚印、水波、尘埃）是最难处理的类别，CORE-AES 显著较低。
- **上下文丢失问题**：许多掩码方法在推理前将掩码区域置零，丢弃了透过半透明对象可观察到的背景信息，迫使其“幻觉”内容，不利于因果一致恢复。
- **CORE 与人类判断更对齐**：
  - CORE Gemini 与人类评分的 Spearman 相关：OS 0.62、AES 0.73（GPT 版为 0.60/0.76）；
  - 人类标注者间一致性为 OS 0.69、AES 0.79；
  - 像素指标与人类评分的相关接近零甚至为负，验证了像素指标的失效。
  - ICC 显示 CORE 评分具有良好稳定性（OS 0.808、AES 0.882）。
- **重新定义任务**：视频对象移除应被视为“因果场景一致性”问题，而非局部重建问题。

## 7. 优点

- **视角创新**：首次系统地将视频对象移除定义为因果干预，并据此设计基准与评估指标，具有方法论上的示范意义。
- **数据设计合理**：
  - 提供时间对齐的配对干净背景，支持直接的反事实比较；
  - 合成与真实数据互补，兼顾可控性与现实性；
  - 掩码刻意排除余效，能考察模型的物理推理能力而非简单修复能力；
  - 同时支持掩码和指令提示，适应现代编辑模型。
- **评估指标先进**：CORE 将 VLM 评估从单帧真实性判断提升为多视频结构化比较，明确分离“对象移除”和“余效消除”两个维度，且经人类相关性验证。
- **实验揭示重要现象**：系统地展示了现有模型在“视觉合理”与“因果正确”之间的差距，对领域有诊断价值。

## 8. 不足与局限

- **数据集规模与平衡**：180 个视频相对较小，且类别分布不均衡（阴影 127 而蒸汽仅 20），部分类别的结论置信度有限。
- **合成数据偏差**：Veo 3 生成的视频可能带有生成模型自身的伪影，未必能完全代表真实物理过程。
- **真实数据采集局限**：两次拍摄之间即使固定机位，也可能存在轻微光照或环境波动，并非严格意义上“唯一差异为对象存在”的完美配对。
- **评估依赖 VLM**：CORE 虽与人类判断相关较好，但 VLM 本身可能存在对某些物理现象的盲区，且评分成本较高、可解释性有限。
- **公平性风险**：不同方法使用默认配置，但未进行超参数调优，可能对某些方法不公平。
- **缺乏消融与统计检验**：未对 CORE 的提示设计进行消融，也未报告置信区间或显著性水平。
- **图像方法比较局限**：OmniPaint、ObjectClear 为单帧模型，逐帧处理忽略时间一致性，对比结果不能直接反映视频移除能力。
