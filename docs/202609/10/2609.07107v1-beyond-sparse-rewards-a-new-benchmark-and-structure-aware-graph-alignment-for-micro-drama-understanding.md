## 摘要
微短剧以超短时长和高密度剧情为特征，给视频理解带来了传统基准无法应对的独特挑战。为弥合这一差距，我们提出 M-Drama，首个面向微短剧理解的大规模双语基准，涵盖 9,138 个片段、超过 3.5 万个实例。此外，尽管强化学习可以增强 VLM 处理复杂叙事的能力，但现有奖励指标往往受限于稀疏且浅层的信号，无法捕捉错综复杂的人物身份和时序结构。我们提出 SAGA（Structure-Aware Graph Alignment，结构感知图对齐），一种新颖的图匹配奖励函数，将叙事建模为异构图。SAGA 通过解耦的语义三元组匹配和结构化时间匹配计算稠密且严格的奖励。在 Qwen3-VL-8B-Instruct 上的大量实验表明，SAGA 优于现有基线，在开放式准确率和摘要质量上带来显著提升，同时保持具有竞争力的域外泛化能力。代码见 https://github.com/qyx1121/MDrama_SAGA。

## Abstract
Micro-dramas, characterized by ultra-short durations and hyper-dense storylines, pose unique challenges for video understanding that conventional benchmarks fail to address. To bridge this gap, we introduce M-Drama, the first large-scale bilingual benchmark for micro-drama comprehension, featuring over 35K instances across 9,138 clips. Furthermore, while reinforcement learning can enhance VLMs on complex narratives, existing reward metrics often suffer from sparse and superficial signals, failing to capture intricate character identities and temporal structures. We propose SAGA (Structure-Aware Graph Alignment), a novel graph-matching reward function that models narratives as heterogeneous graphs. SAGA computes dense, rigorous rewards via decoupled semantic triplet and structural temporal matching. Extensive experiments on Qwen3-VL-8B-Instruct demonstrate that SAGA outperforms existing baselines, delivering substantial improvements in open-ended accuracy and summary quality, while maintaining competitive out-of-domain generalization. Code is available at https://github.com/qyx1121/MDrama_SAGA.

## 2. 方法论

### 2.1 核心思想

- 采用 **SFT → RL 两阶段范式**，并设计三段式输出格式强制模型先显式陈述视觉观察再推理：
  `<caption> [视频描述] </caption> <think> [思考过程] </think> <answer> [回答] </answer>`
- 将微短剧叙事建模为**异构图 G=(V,E)**，节点分四类：**Character**（严格 `Role(Name)` 格式）、**Event**、**Prop**、**Scene**；边分两类：**语义边**（AGENT_OF、TARGET_OF、HAS_PROP、LOCATED_IN）与**结构边**（NEXT_EVENT，表示时序）。
- 奖励由两条解耦通路构成：**语义三元组匹配**解决实体/事件混淆，**结构时间匹配**保证时序保真。

### 2.2 关键技术细节

**（a）语义三元组匹配**

- **实体匹配（级联规则）**：
  - 从 `Role(Name)` 提取核心名；
  - 对所有格关系（如"John's mother"）施加严重惩罚 λ_poss=0.30；
  - 若核心名存在词级子集关系（"Anderson" ⊂ "Peter Anderson"）则强制 sim=1；
  - 若双方均解析出核心名且完全不一致则 sim=0；
  - Prop/Scene 节点若存在部分子串包含（"kitchen table" vs "kitchen"）施加 λ_cont=0.50 惩罚。
- **事件匹配（邻域指纹）**：为每个事件定义由其**非事件邻居**按关系类型分组构成的邻域指纹；对每种关系 r，用**匈牙利算法**对齐邻居集合，按关系权重加权聚合为 sim_nbr（w_agent=1.5、w_target=1.2、w_loc=0.8、w_prop=0.5）；最终 `sim_event = α·sim_emb + (1-α)·sim_nbr`，α=0.65。
- **三元组评分**：对 GT 与预测三元组集合做全局**二分匹配（匈牙利算法）**，若关系或节点类型不匹配则相似度严格置 0；否则 `s_ij = ½(sim(h,h') + sim(t,t'))`，最终计算软 F1：

  `P_sem = Σs_ij / |T_pred|`，`R_sem = Σs_ij / |T_gt|`，`F1_sem = 2·P_sem·R_sem / (P_sem + R_sem)`

**（b）结构时间匹配**

- 为避免 NEXT_EVENT 严格匹配过刚，先计算**传递闭包 O(G)**（A→B→C 可推出 (A,B)、(A,C)、(B,C)），对省略中间事件但整体叙事流正确的情况给予部分得分。
- 定义正确预测的时序对集合 `M_temp = {(e_i,e_j) ∈ O_gt | (φ(e_i), φ(e_j)) ∈ O_pred}`，其中 φ 为语义匹配阶段的事件映射。
- 计算 `P_struct`、`R_struct` 与 `F1_struct`。

**（c）优化目标**

- 中间 caption 奖励：`R_cap = β·F1_struct + (1-β)·F1_sem`，β=0.30。
- 最终答案奖励 `R_ans`：MC 用精确匹配（0/1），生成任务用 LLM-as-Judge。
- 基于 **DAPO** 目标，引入**分段掩码**：`I_cap(y_i,t)` 仅覆盖 `<caption>` 块，`I_ans ≡ 1` 覆盖全序列；总损失：
  `L_total = -[(1-γ)·J_ans(θ) + γ·J_cap(θ)]`，γ=0.75。

**（d）数据准备与轨迹采样**

- 用冷启动 SFT checkpoint 为每条实例生成 6 条候选轨迹；
- OE/Summary 用 ROUGE-L、CIDEr 阈值二值化，MC 用精确匹配；
- 剔除 6/6 全对的平凡样本，按正确数分为 easy(4~5)、middle(1~3)、hard(0)，优先采样 middle > hard > easy，生成任务优先于 MC；每视频最多 2 样本，最终保留 **44%** 高质量轨迹。

## 6. 主要结果与结论

### 6.1 主结果

- **零样本对比**：闭源旗舰（GPT-5、Gemini-3-Flash）在 M-Drama 上仍显著落后于经过训练的 8B 模型，说明微短剧的叙事密度对通用 VLM 构成实质性挑战；开源模型中 Qwen3-VL-8B-Instruct 表现相对最优，被选为统一骨干。
- **训练方法对比**：在相同骨干与配置下，SAGA 在三类任务（MC / OE / Summary）上均优于 CS-SFT、标准 DAPO、DAPO + VideoCap-R1、DAPO + AutoDQ，验证了结构感知奖励相对于词法奖励与通用视频奖励的优势。
- **域外泛化**：在 ShortVid-Bench、Video-MME（无字幕）、Video-Holmes 上，SAGA 训练的模型未出现明显性能退化，部分任务甚至有提升，表明结构对齐奖励学到的叙事推理能力具有一定可迁移性。

### 6.2 消融结论

- **双组件缺一不可**：去掉 F1_struct 或 F1_sem 均导致性能下降，且**同时去掉两者**时降幅最大，说明语义三元组匹配与结构时间匹配解决的是两类互补错误——前者抑制人物/物体/场景混淆，后者抑制时序扭曲。
- **结构奖励的边际贡献**：在涉及情节顺序、因果推理的任务（Plot Comprehension、Narrative Analysis、Logical Reasoning）上，F1_struct 的贡献更为突出；在实体识别类任务（Character Identification、Key Object Interaction）上，F1_sem 的作用更明显，与设计动机一致。

### 6.3 细粒度与可靠性结论

- **摘要质量**：SAGA 在 Accuracy、Fluency、Completeness 三个维度上均取得更均衡的分数，且分数分布更集中于高分区间，说明其不仅"答对"，还减少了冗长堆砌。
- **奖励可靠性**：图构建的人工审计显示节点错误率仅 0.37%、边错误率 3.70%，构建质量较高；在 10%~50% 四类噪声注入下，SAGA 的性能衰减曲线比标准 DAPO 更平缓，说明奖励函数对图噪声具有鲁棒性。
- **评估可靠性**：人工-LLM 一致性（κ≈0.74~0.78）与双 judge 相关性（0.76~0.78）均处于可接受水平，成对偏好人工校验一致率 86%~88.5%，支撑了自动评估结论的可信度。

## 7. 局限性

- **模态覆盖单一**：M-Drama 仅包含视觉 + 文本（字幕/对白），未纳入音频、音乐、音效等线索，而微短剧的情绪张力与反转节奏常依赖配乐与音效。
- **语言与文化边界**：虽为中英双语，但微短剧的题材（家庭伦理、逆袭、复仇等）带有较强文化特异性，跨文化泛化尚未验证。
- **奖励构建成本**：每部剧需构建异构图，依赖外部 LLM 与嵌入模型，训练前的图构建开销未被量化，可能限制大规模扩展。
- **未报告训练时长**：缺乏 GPU 小时数与墙钟时间，难以评估方法的实际训练成本与可复现性。
- **人工评估规模有限**：奖励审计 251 张图、评估一致性 513 条，相对于 35,472 条实例总量而言样本较小，统计效力有限。

## 8. 启示与展望

- **基准层面**：M-Drama 填补了"微短剧"这一高叙事密度形态的评测空白，其九类任务划分与叙事密度指标（事件密度、人物密度）可为后续短视频理解基准提供设计参考。
- **奖励设计层面**：SAGA 将"解耦"思想引入奖励函数——把语义匹配与结构匹配分离，再通过加权融合，这一范式可迁移至其他长程推理任务（如长视频问答、多步工具调用），避免单一奖励信号被某类错误主导。
- **训练范式层面**：`<caption>→<think>→<answer>` 的三段式输出与分段掩码相结合，为"先观察后推理"的可解释 RL 训练提供了可操作的工程模板。
- **未来方向**：可探索（1）多模态图（引入音频节点与情绪边）；（2）图构建与策略的联合优化，降低对外部构建器的依赖；（3）将 SAGA 推广到更长视频与多轮对话场景，检验结构奖励的可扩展性。
