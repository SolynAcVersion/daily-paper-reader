## 摘要
相机条件世界模型生成交互式视频，其中所指令的动作应引发预期的场景变化，同时外观、几何和时间动态保持连贯。现有奖励分别评估这些要求：基于几何的奖励估计轨迹执行情况，但无法判断所执行运动的视觉质量；而基于图像的奖励衡量帧质量，但不捕捉动作执行或时间动态。我们认为，视觉-语言模型（VLM）为将动作与其视觉结果联系起来提供了共享的推理空间。然而，针对完整的动作序列评判完整的长时间视频会形成冗长且嘈杂的上下文，其中短期的局部动作证据可能被遗漏或稀释。我们提出了WorldReward，一种基于VLM的成对偏好奖励模型，统一了相机条件世界模型的动作一致性和视觉质量评估。WorldReward将成对视频分解为与动作对齐的块，将每个块组织成结构化的视觉证据，并通过投票将块级决策聚合为独立的视频级动作和视觉质量偏好。为了训练它，我们使用由前沿VLM生成的结构化判断构建了一个大规模推理增强的偏好数据集，并通过基于工具的代理审计和针对性的人工审查进行细化。我们进一步引入了WorldReward-Bench，一个人工标注的基准，衡量奖励模型与人类偏好在动作一致性、外观质量和运动质量方面的一致性。WorldReward在所有三个维度上取得了最高的一致性，分别超过GPT-5.5 3.42、1.45和3.56个百分点。当用于HY-WorldPlay 1.5的RL后训练时，它在短期到长期的视野中持续改善动作执行和视觉质量。

## Abstract
Camera-conditioned world models generate interactive videos in which commanded actions should induce the expected scene changes while appearance, geometry, and temporal dynamics remain coherent. Existing rewards assess these requirements separately: geometry-based rewards estimate trajectory execution but cannot judge the visual quality of the executed motion, whereas image-based rewards measure frame quality without capturing action execution or temporal dynamics. We posit that a vision-language model (VLM) offers a shared reasoning space for relating actions to their visual outcomes. However, judging a complete long video against its full action sequence creates a lengthy, noisy context in which short-lived local action evidence can be missed or diluted. We present WorldReward, a VLM-based pairwise preference reward model that unifies action-consistency and visual-quality evaluation for camera-conditioned world models. WorldReward decomposes paired videos into action-aligned chunks, organizes each chunk into structured visual evidence, and aggregates chunk-level decisions by voting into separate video-level action and visual-quality preferences. To train it, we construct a large-scale reasoning-augmented preference dataset using structured judgments generated by a frontier VLM and refined through tool-based agent auditing and targeted human review. We further introduce WorldReward-Bench, a human-annotated benchmark measuring reward-model agreement with human preferences across action consistency, appearance quality, and motion quality. WorldReward achieves the highest agreement on all three dimensions, exceeding GPT-5.5 by 3.42, 1.45, and 3.56 percentage points, respectively. When used for RL post-training of HY-WorldPlay 1.5, it consistently improves both action execution and visual quality across short- to long-term horizons.

- **研究背景**：相机条件（camera-conditioned）世界模型用于生成交互式视频，视频内容需随键盘/鼠标等输入的动作指令而变化，同时保持场景外观、几何结构与时间动态的连贯性。这类模型在生成质量评估与强化学习后训练中，都依赖“奖励模型”提供反馈信号。
- **核心问题**：现有奖励模型将“动作执行”与“视觉质量”割裂评估：
  - 基于几何轨迹估计的奖励（如 DepthAnything3、WorldMirror）只能判断相机轨迹是否匹配指令，无法判断执行动作时的画面是否自然、稳定、无伪影；
  - 基于图像/帧质量的奖励（如 HPSv3、视频美学模型）只能感知视觉质量，无法验证指令动作是否被忠实执行；
  - 通用 VLM 整体评判视频又会因上下文过长、局部动作证据短暂而被稀释或遗漏。
- **研究目标**：提出一种统一两种评估信号的 VLM 奖励模型，使其既能判断“指令动作是否被正确执行”，也能判断“执行后的视频外观与动态质量是否合格”，并可分解为独立的动作偏好与视觉质量偏好，用于世界模型的评估与 RL 后训练。
- **整体含义**：论文主张用 VLM 提供“共享推理空间”，通过局部化、结构化的动作-视频证据，把“动作-视觉结果”的耦合关系在同一模型中统一建模，从而替代由多个异构系统拼装而成的奖励信号。

## 2. 方法论

### 2.1 核心思想：局部到全局的分块推理

- 由于整段长视频包含大量动作，单次整体推理会稀释局部动作产生的短时视觉证据，因此论文将视频与动作轨迹按时间对齐，切分为固定大小的**动作块（chunk）**。
- 具体设置：在动作序列前加入一个与源图片对齐的“空闲（idle）”槽位后，每 4 个动作为一个 chunk。训练数据的 11 步轨迹加 idle 共 12 个槽位，形成 3 个 chunk；评测/后训练用更长轨迹时则生成更多 chunk。
- 每个 chunk 只包含 4 个动作对应的视频片段，输入规模小且与动作强对齐，便于 VLM 做细粒度判断。

### 2.2 结构化视觉输入

给定两个候选视频 A/B，其共享同一源图、同一文本描述与同一动作轨迹。WorldReward 对每个 chunk 构造包含六路图像证据的输入：
- **源图像（source image）**：作为场景身份参考，用于检测“源场景漂移”或物体/布局/光照变化；
- **帧网格总览（frame-grid overview）**：显示每个动作的起始、中间、结束三帧，用于判断时间一致性、动态生成强度；
- **每个动作的细节面板（action-level panel）**：仅显示该动作的“首帧 vs 末帧”对比，便于逐动作核对局部场景变换是否符合指令方向（如“前移应放大”、“左转应右移”）。

输入还附带图像文本描述和局部动作序列，为模型保留语义上下文。

### 2.3 分块级的奖励推理

对每个 chunk，WorldReward 输出两类决策：
- **动作一致性（action）**：逐动作比较 A/B 是否按指令方向产生场景变化，再汇总为 chunk 级的动作赢家；
- **视觉质量（visual）**：从三个子维度联合判断：
  1. **时间一致性（temporal consistency）**：帧间是否稳定、无闪烁、无纹理滑动；
  2. **动态生成质量（dynamic generation quality）**：运动是否体现真实 3D 相机动态（如视差）而非 2D 平移缩放；
  3. **伪影与结构完整性（artifacts & structure integrity）**：是否出现结构形变、生成伪影或源场景内容被篡改。

输出动作赢家与视觉赢家，取值均为 {A, B, Tie}。

### 2.4 投票聚合得到视频级偏好

对全部 K 个 chunk，用多数投票决定总视频/长序列级偏好：
- 对维度 m，若 candidate A 获胜块数多于 B，则总偏好为 A，反之 B，相等为 Tie；
- 由此分别得到 **action 全局偏好**与 **visual-quality 全局偏好**，两者可独立用于 RL 信号，但来自同一模型的同一份局部证据推理。

### 2.5 训练数据构建：推理增强的偏好数据流水线

- 阶段一：准备输入条件（源图+描述+动作轨迹），覆盖不同内容类别（场景、建筑、自然等）、视觉风格（写实、动漫、游戏、艺术画等）与轨迹类别（纯平移、纯旋转、复合动作、往返、对角移动等）。
- 阶段二：用 8 种世界模型产生匹配视频对（如 HY-WorldPlay、LingBot-World-Fast、Infinite-World、Yume-1.5、SANA-WM、Matrix-Game 等），约束同一条件在同一轨迹下生成，保证偏好差异来自生成质量而非条件改变。
- 阶段三：先用 Gemini 3.1 Pro 按上述 chunk 协议蒸馏结构化推理标注；再用 GPT-5.5 工具代理（agent harness）做多轮质量审计，自动调用图像读取工具逐块核对并输出局部 diff；最后对代理修订样本做人工校准。
- 最终数据集包含约 99,954 个原始 chunk 级样本；经候选位置交换增强（position-swap augmentation）后约为 124,942 个训练样本。

### 2.6 训练目标

采用多模态 LLM 的监督微调，优化标准自回归条件语言建模目标：

\[
\mathcal{L}_{\rm SFT}(\theta)=-\frac{1}{\sum_{i=1}^M L_i}\sum_{i=1}^M\sum_{t=1}^{L_i}\log p_\theta(s_{i,t}\mid z_i,s_{i,<t})
\]

即在结构化多模态输入条件下，让模型生成包含动作推理、视觉质量推理与最终偏好标签的文本响应。

### 2.7 用于 RL 后训练的奖励形式

- 保留 WorldCompass 的 clip 级 rollout 与 DiffusionNFT 优化框架，仅替换奖励来源。
- 每个候选 clip 与前缀条件对齐后，用 WorldReward 对候选对 \(\{i,j\}\) 产生动作赢家和视觉赢家，再按 Pref-GRPO 的获胜率形式转换为每个候选的奖励：

\[
R^m_i=\frac{1}{G-1}\sum_{j\ne i}\omega_i(y^m_{ij}),\quad m\in\{\text{act},\text{vis}\}
\]

其中获胜贡献：该候选胜 =1，Tie=1/2，负=0。
- 对每个 rollout group 内对两种奖励做独立标准化，然后按线性加权组合为最优性概率，并使用 DiffusionNFT 的正负速度预测目标优化流匹配模型。

### 3.3 对照实验的关键结果

- 总体一致性（三分类准确率，Tie 作为显式标签）：
  - Action：WorldReward 77.63%，高于 GPT-5.5 的 74.21%；
  - Appearance：WorldReward 81.32%，高于 GPT-5.5 的 79.87%；
  - Motion：WorldReward 73.03%，高于 GPT-5.5 的 69.47%；
  - 三项分别高出 3.42、1.45 和 3.56 个百分点。
- 轨迹组与风格子集的泛化：在平移/旋转/复合轨迹、写实/游戏动漫/艺术风格等分组中，WorldReward 多数取得第一。
- RL 后训练：相对 WorldCompass，WorldReward-RL 在三个视界上均提升结合动作与基础动作精度，并同时提高 HPSv3 分数；长视界结合动作 Action 56.40 vs 54.82，Quality 1.02 vs 0.73。
- 消融实验：
  - 去掉源图、帧网格、动作面板分别导致外观/动作/运动一致性下降；
  - 仅有偏好标签不如增加总体摘要，也不如再增加逐视频分析；
  - 不做 agent 审计则蒸馏提升有限；agent 审计是主要增益来源；人工校准进一步提升；

  - 仅用动作奖励的模型行动精度较高但画质偏弱；仅用视觉奖励则画质改善但动作提升有限；两者并用最佳。

### 3.4 组级 vs 样本级人类一致性

- 在 200 对人类评估子集上，WorldReward 与 GPT-5.5 不仅在总体选择上一致，在与个体人类标注的逐对一致性上也接近：Action 70.3% vs GPT-5.5 69.1%，Visual 72.9% vs 72.0%（95% bootstrap CI 未显示显著差异）。

  - 主基准（WorldReward-Bench）的标签来自三人多数票，但并未报告标注者间一致率（如 Cohen's kappa），难以判断三人主观判断的可复现性；
  - 多数指标基于一个模型族的输出与世界模型池，若世界模型分布扩展（如更极端风格、超长视界、更大运动幅度）后稳定性仍需检验；
  - 论文没有报告训练数据中“Tie”的比例以及最终模型在 Tie 上的行别精度，低 Tie 样本下准确率可能对候选对优劣悬殊较敏感；
  - GPT-5.5/Gemini 同时作为标注教师与对比基线的身份可能带来不公平优势，论文通过 agent 审计与人工校准来缓解，但仍值得注意；
  - 消融表未给出置信区间或显著性检验，差异是否统计显著不明确；
  - 算力报告缺失，使可复现性与工程成本评估受限。

## 6. 主要结论与发现

- VLM-based 的分块式成对奖励能统一评估动作执行与视觉质量，无需依赖异构的几何+图像奖励系统。
- “局部证据结构化 + 分块投票聚合”的推理范式能有效避免长视频整体评判造成的动作证据稀释。
- 三阶段数据流水线中，蒸馏本身不足以超越教师模型；**agent-harness 审计**是核心增益来源，人工校准提供进一步改善，最终模型能超过其标注教师（Gemini 3.1 Pro 与 GPT-5.5）。
- 结构化视觉输入（源图、帧网格、动作面板）和分层推理监督（偏好标签→总体摘要→逐视频分析）均会显著影响最终一致性。
- 作为 RL 奖励使用时，动作与视觉两个偏好能互补——动作信号提升轨迹服从性，视觉信号避免动作执行时画质坍塌，二者共同提升长视界生成质量。
- 与人类评估者在逐对样本上的一致性接近 GPT-5.5，说明其在用于优化自身后训练时仍与人类偏好保持对齐。

## 7. 优点

- **问题设计清晰**：正确定位“动作执行”和“视觉质量”在相机条件世界模型中的耦合关系，并不将其简单相加。
- **推理范式合理**：分块 + 结构化证据 + 投票聚合，既降低长视频上下文压力，又保留局部动作证据，设计动机具体且有消融支持。
- **数据质量控制新颖**：使用工具代理（GPT-5.5）对教师蒸馏标注做多轮局部审计，并用人校准“审计被修订样本”，将人工成本集中在最可能有错的地方，具有工程实用价值。
- **实验设计规范**：训练/评测轨迹库分离，RL 后训练保持单变量控制，只替换奖励信号，并使用 GPT-5.5 与人工评估三重验证；
- **成对偏好与三分类 Tie 设计**：允许“模糊一致”情形，符合真实生成本质上“难以区分或各有所长”的情况；
- **通用性较好**：同一输入既可评测也可同时提供 action/visual 两种 RL 信号，可作为相机条件世界模型后处理/评测的通用偏好先验。

## 8. 不足与局限

- **算力开销不透明**：论文未报告训练时间、GPU 数量和总 API 成本，影响工程可复现性。
- **教师模型依赖与潜在偏差**：标注教师为 GPT-5.5/Gemini 3.1；即使有 agent 审计与人工校准，仍可能存在教师对某些伪影/动作判别的系统性偏好。
- **基准规模有限**：760 对基准在轨迹多样性和动态范围上仍远小于真实开放世界；对长几百帧以上的更复杂控制尚无充分评测。
- **评价指标单一**：只报告三项三分类准确率，缺少对 Tie 分布的分析，也缺少与真实轨迹精度的数值关联（例如动作一致性是否精确预测 DAv3 轨迹误差）。
- **跨域泛化边界未测**：训练覆盖了写实、游戏/动漫和艺术风格，但对极端风格、抗扰模糊、遮挡严重的场景表现未知。
- **RL 后训练评测仍依赖第三方几何/图像代理指标**：DepthAnything3 与 HPSv3 本身存在误差，因此世界模型改进量可能受代理指标的系统性偏移影响。
- **无负面案例或失败模式剖析**：未讨论 WorldReward 在哪些动作-视频组合上仍易误判，对系统性的局限（如视频间同步、动作起止标注噪声）讨论不足。
