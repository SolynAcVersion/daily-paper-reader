## 摘要
高效、全自动且物理上合理的4D高斯合成是动态场景生成的重要目标。近年来，基于物理的方法将3D高斯与物质点法（MPM）相结合，以生成由物理驱动的运动，但将这一范式扩展到异构多部件物体和交互式多物体场景仍然具有挑战性。物体级物理分配会将不同部分坍缩为单一物质状态，而来自大型语言模型、视觉语言模型或智能体的一次性预测既不能可靠地将不同材质绑定到已识别的部件上，也无法验证由此产生的MPM配置是否可执行。同时，基于分数蒸馏采样（SDS）的参数优化需要重复的逐场景分数评估和梯度反向传播，导致优化时间冗长，并可能产生次优或不稳定的解。因此，我们提出了PhysMAS，一个基于物理的多智能体框架。从一个运动提示和四个场景视图出发，一个物体-部件场景智能体建立持久身份，并调用一个材质推理智能体来获取部件级描述。它调用具备求解器意识的技能，将这些身份和描述绑定到逐粒子MPM场中，并在共享域中执行所有物体；随后，该框架筛选候选的正向模拟结果。这支持异构多部件和交互式多物体场景，无需逐场景扩散分数反向传播。大量实验表明，与依赖SDS的近期基于物理的4D高斯基线相比，PhysMAS在语义对齐和感知物理合理性方面取得了更好的结果，同时所需运行时间更少。

## Abstract
Efficient, fully automatic, and physically plausible 4D Gaussian synthesis is an important goal for dynamic scene generation. Recent physics-based methods couple 3D Gaussians with the Material Point Method (MPM) to generate physically driven motion, but extending this paradigm to heterogeneous multi-part objects and interacting multi-object scenes remains challenging. Object-level physical assignment collapses distinct parts into a single material state, while one-shot predictions from large language models, vision-language models, or agents neither reliably bind different materials to identified parts nor verify that the resulting MPM configuration is executable. Score Distillation Sampling (SDS)-based parameter optimization, meanwhile, requires repeated per-scene score evaluations and gradient backpropagation, incurring lengthy optimization and potentially yielding suboptimal or unstable solutions. We therefore present PhysMAS, a physics-grounded multi-agent framework. From a motion prompt and four scene views, an Object-Part Scene Agent establishes persistent identities and calls a Material Reasoning Agent for part-wise profiles. It invokes solver-aware skills to bind these identities and profiles to per-particle MPM fields and execute all objects in a shared domain; the framework then screens candidate forward-simulation results. This supports heterogeneous multi-part and interacting multi-object scenes without per-scene diffusion-score backpropagation. Extensive experiments demonstrate that, compared with recent physics-based 4D Gaussian baselines that rely on SDS, PhysMAS achieves better semantic alignment and perceived physical plausibility while requiring less runtime.

## 1. 论文的核心问题与整体含义

**核心问题：** 如何在物理驱动的 4D 高斯合成中，高效、自动地处理**异构多部件物体**（如蛋糕的基底/浇头/盘子）与**交互多物体场景**（如锤子砸到蛋糕上），并生成符合真实物理规律的高质量动态序列。

**研究背景与现有方法的局限：**
- 现有物理驱动方法（如 PhysGaussian）将 3D 高斯与物质点法（MPM）耦合来生成物理运动，但通常只在**物体级或高斯场级**赋予物理属性，缺乏“部件-父物体”的显式层次结构，无法区分不同结构角色和材质响应的部件。
- 基于 SDS 的方法（如 DreamPhysics、OmniPhysGS 等）虽可利用视频先验优化参数，但需要**逐场景重复分数评估与梯度反向传播**，优化时间长、易不稳定。
- 一次性 LLM/VLM 预测虽然可以提出材质标签与参数，但无法保证被 MPM 接受和执行，缺乏“可执行性验证”。

**PhysMAS 的整体思路：**
> 构建一个基于物理的多智能体框架：场景智能体负责对象/部件身份识别与规划，材料智能体负责逐部件材料推理，然后通过一组**具备求解器意识的确定性技能**将身份与材料绑定到 MPM 粒子场、在共享域中执行仿真，并**筛选可执行的候选结果**——全程无需逐场景扩散分数反向传播。

## 2. 方法论

### 2.1 核心思想

PhysMAS 的输入为：一个运动提示（motion prompt）、四个校准 RGB 视图及其对齐的静态 3DGS、指定输出相机。输出为符合条件的动态 4D 高斯序列。其核心设计在于将场景组织解构为**“持久对象-部件状态”**，以此作为视觉感知、材料推理、MPM 编译、仿真执行与筛选验证之间的统一接口。

### 2.2 双智能体架构

- **对象-部件场景智能体（Object-Part Scene Agent）：**
  - 使用 Grounding DINO 和 SAM 2 获得掩码与置信度；
  - 先识别对象，再在同对象内比较部件证据，形成稳定的部件级标签；
  - 负责构造场景计划 Π（角色、动作目标、方向、幅度、活动间隔）；
  - 唯一拥有更新对象/部件身份、调用工具、接受滚动的权限。

- **材质推理智能体（Material Reasoning Agent）：**
  - 对每个活动部件行 r，结合高亮多视图观察、视觉-语言材料分数和冻结的裁剪条件物理属性预测器（crop-conditioned predictor），输出该部件的材料档案：材料分支 β、杨氏模量 E、泊松比 ν、密度 ρ；
  - 输出被约束在六种可接受的仿真器配置域 K_sim 内（Jelly / Metal / Sand / Foam / Snow / Plasticine）。

### 2.3 确定性“求解器感知”技能（Solver-Aware Skills）

- **候选构建：** 确定性地将材料证据转换为若干材料候选（如后验 MAP、目标冲击、硬支撑绑定、求解器兼容、软/硬变量、不确定性扫掠、替代材料等），保留结构支撑/界面相关控制参数。
- **粒子编译：** 高斯均值经变换映射到归一化 MPM 空间；前 N_G 个粒子为高斯均值本身，其余粒子为填充粒子（保留源对象身份和最近高斯索引）。每个粒子绑定所属行、候选参数和质量：M_q = ρ_q · V_q⁰。
- **共享域模拟：** 所有对象在单一速度网格中执行标准 APIC-MPM 更新（P2G → grid update → G2P），粒子共享同一网格场，从而自然实现多对象间的动量交换与碰撞交互。支持结构保持投影（将支撑体粒子约束在初始形态附近以减少异常变形撕裂）。
- **高斯传输与渲染：** 粒子状态变换回高斯参数（新均值 μ = L⁻¹(x − d)、协方差 Σ = FΣ₀Fᵀ），生成 4D 高斯渲染序列。
- **可执行候选筛选：** 计算过程、数值、伪影与端点诊断；通过有效性门控和可执行性评分 Q_exec 进行排序，循环最多 3 轮候选执行-修复-再评估，最终经完整工件审计后接受。

## 6. 主要结论与发现

1. **持久对象-部件身份建模有效：** 从感知、材料推理到 MPM 编译，层层保持可与部件地址的条目化状态，使异构部件不再被人为统一为单一材质状态。
2. **无需 SDS 反向传播也能取得更优结果：** PhysMAS 在六种材质轮廓和多物体条件下，均获得最高的平均 CLIP 相似度和用户偏好率，同时误差最小。
3. **运行时优势显著：** 相比 SDS 类方法速度提升数十倍甚至数百倍（2 min vs. >12 h），证明物理智能体与确定性编译路线的高效性。
4. **共享网格交互有效：** 多物体在单一速度场的 MPM 域内执行，足以支撑交互式多物体动态生成。

## 7. 优点

- **层次化状态设计：** 引入了“面向对象的部件表”（object-scoped part table），将感知到的物体/部件身份延伸到材料候选、粒子编译与可执行筛选全流程，具有可追溯性。
- **双智能体可审计框架：** 场景智能体负责身份/规划/验收，材料智能体只返回行级证据，职责分离明确；确定性的编译、模拟、修复与排名均由固定程序完成，避免大模型“越权”输出不可执行参数。
- **工程化可靠性：** 支持候选构建与判断（candidate construction）、显式有效性门控（validity gate）、量化可执行评分和修复循环，将“不可执行”的输出在仿真前或仿真的早期阶段过滤掉。
- **高效且实用：** 在 RTX 4090 单卡上 2 分钟产出 50 帧动态 4D 序列，远超 SDS 方案的相对耗时。
- **物理保真度高：** 结构保持投影显式抑制支持体部件的非物理拉伸/撕裂，界面保持投影防止贴合部件的视觉分离，实验证明其改善明显。

## 8. 不足与局限

- **跨视角绑定受限：** Persistent object-part 分配依赖四个视图的可见性掩码，对于遮挡严重或细长部件可能不稳定；论文也提到未来需要遮挡感知的跨视图关联。
- **材质剖面与交互类型有限：** 目前仅支持六种材质分支（Jelly/Metal/Sand/Foam/Snow/Plasticine）、有限的支撑/粘结变换与共用的本构参数。铰接关节、拓扑更新、摩擦断裂等情景未覆盖。
- **空间/时间尺度受限：** 固定 100³ 网格与短序列（50 帧），缺乏自适应粒子/网格与长时序大规模动作规划。
- **评测偏差风险：** 运动/变形误差需要配对参考视频（参考质量直接影响结果）；CLIP sim 对“语义-视觉一致”的表征不完全等同于人类感知；UPR 参与者为学术研究背景的 CV/CG 人员，一般化能力有待更大规模用户调研验证。
- **计算对比环境不完全对等：** PhysMAS 相比基线省去了 SDS 优化但额外使用了 Grounding DINO + SAM 2 + 大型语言模型（Qwen3.7-Plus）的推理成本，论文仅报告总运行时间为 2 分钟，未单独拆解感知/材料推理与仿真的耗时构成。
