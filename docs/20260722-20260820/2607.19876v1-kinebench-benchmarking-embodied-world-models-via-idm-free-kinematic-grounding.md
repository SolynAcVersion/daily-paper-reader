## 摘要
评估具身世界模型（EWMs）的物理一致性是一个关键且开放的挑战。尽管通过模拟器 rollout 的闭环评估相比开环替代方案能更忠实地评估物理合理性，但现有框架几乎完全依赖逆动力学模型（IDMs）进行动作提取。由于从2D像素空间到3D运动学空间的复杂映射，学习到的IDM在面对训练分布之外的数据时可能变得脆弱，导致从包含新颖物体和场景的生成视频中提取动作时不可靠。这在世界模型的不准确性与提取器误差之间造成了不可避免的归因模糊性。为减少这种模糊性，我们提出了KineBench，一个基于显式运动学接地流程的、无IDM的EWM闭环基准。给定一个生成视频，KineBench采用级联视觉基础模型直接从各帧提取6D末端执行器位姿，然后在物理模拟器中执行以进行闭环验证。除了基于执行的任务成功率，KineBench还纳入了两个经典3D运动学指标——谱弧长（SPARC）和丸山可操控性指数——以从机器人中心视角刻画轨迹平滑性和运动学可行性。基于ManiSkill3中的20个多样化操作任务，KineBench在四个渐进套件中评估EWM：基本执行、任务迁移、视觉分布外泛化以及复杂度条件缩放。对前沿模型的评估揭示了具身视频生成中任务复杂度有界非线性缩放现象，为未来数据扩展策略提供了经验指导。

## Abstract
Evaluating the physical consistency of embodied world models(EWMs) is a critical open challenge. While closed-loop evaluation via simulator rollouts offers a more faithful assessment of physical plausibility than open-loop alternatives, existing frameworks almost exclusively rely on Inverse Dynamics Models(IDMs) for action extraction. Due to the intricate mapping from 2D pixel space to 3D kinematic space, the learned IDMs can be brittle to data outside their training distribution, resulting in unreliable action extraction from the generated videos with novel objects and scenarios. This creates an unavoidable attribution ambiguity between world model inaccuracies and extractor errors. To reduce this ambiguity, we present KineBench, an IDM-free closed-loop benchmark for EWMs, built upon an explicit kinematic grounding pipeline. Given a generated video, KineBench employs cascaded visual foundation models to directly extract 6D end-effector poses from individual frames, which are then executed in a physics simulator for closed-loop validation. Beyond execution-based task success, KineBench incorporates two classical 3D kinematic metrics--Spectral Arc Length (SPARC) and the Maruyama Manipulability Index--to characterize trajectory smoothness and kinematic feasibility from a robot-centric perspective. Built on 20 diverse manipulation tasks in ManiSkill3, KineBench evaluates EWMs across four progressive suites: basic execution, task transfer, visual out-of-distribution generalization, and complexity-conditioned scaling. Evaluation across frontier models reveals task-complexity-bounded nonlinear scaling in embodied video generation, providing empirical guidance for future data-scaling strategies.

## 1. 核心问题与研究动机

- 具身世界模型（Embodied World Models, EWMs）旨在赋予智能体对物理环境动态的预测能力，近年被直接用于机器人控制（如作为 VLA 模型的预训练骨干或作为模型预测规划器）。
- 评估 EWM 的关键挑战在于：不仅要衡量生成视频的像素质量，更要验证其**物理合理性与可执行性**。
- 现有闭环评估框架大多依赖逆动力学模型（IDM）从生成视频中反推动作。但 IDM 从 2D 像素映射到 3D 运动学空间的能力存在分布外脆弱性，面对生成模型产生的新颖轨迹时容易失效，造成**归因模糊**：无法判断执行失败是源于世界模型生成了物理不合理的视频，还是 IDM 提取动作出错。
- 因此，论文的目标是**消除或显著减少这种归因歧义**，提供一个更可靠、更可解释的闭环评估基准。

## 2. 方法论：KineBench 的设计

- **核心思想**：用“显式运动学接地”替代隐式 IDM 动作提取，即以模块化的几何管线从生成视频中恢复 6D 末端执行器位姿，再在物理模拟器中闭环执行。
- **显式运动学接地管线**：
  1. 使用微调的 YOLO 模型对末端执行器进行 2D 实例分割（夹爪 CAD 模型可直接获取，无需人工标注）。
  2. 使用微调的 MoGeV2 模型进行单目深度估计，得到高精度绝对度量深度图。
  3. 使用 FoundationPose 进行 CAD 约束的 6D 位姿估计与跟踪，通过 Render-and-Compare 范式最小化渲染 CAD 与观测帧之间的光度/几何残差。
  4. 刚性约束可抑制高帧率抖动等局部视觉噪声；对于夹爪消失、空间大幅不连续等物理幻觉则产生不稳定或不可行的位姿估计，因此具有类似“低通滤波”的效果。
  5. 提取的位姿序列在 ManiSkill3 物理模拟器中执行，得到下一个观测，再输入给世界模型，形成闭环。
- **机器人中心运动学指标**：
  - **SPARC（Spectral Arc Length）**：在频域中衡量轨迹平滑度，定义为归一化傅里叶幅度谱的弧长（负值）；模型生成抖动或瞬移时，SPARC 显著下降。
  - **Maruyama Manipulability Index**：基于雅可比矩阵行列式 \( w = \sqrt{\det(J(q)J^T(q))} \)，衡量机器人运动学可操控性与奇异位形规避能力；若生成位姿超出关节约束，该指标会急剧下降。
- **四套渐进式基准套件**，共 20 个操作任务：
  - Suite 0：基本执行（I.I.D. 设置）。
  - Suite 1：任务迁移（零样本迁移到概念相关但不同的任务）。
  - Suite 2：视觉分布外（OOD）泛化（训练与评估使用不重叠的物体实例和背景）。
  - Suite 3：复杂度条件缩放（通过变化训练数据量和计算量，研究任务复杂度对收益的影响）。

## 3. 实验设计

- **环境与任务**：基于 ManiSkill3 物理模拟器，设计 20 个操作任务，包括基本的 reaching、刚性物体抓取、带障碍物的操作、多轴铰接物体操控（X/Y/Z 轴）以及长时序组合任务。
- **Benchmark 结构**：四个套件（S0–S3），每套对应不同的泛化维度；S3 中通过控制专家轨迹数（10–100）和优化步数（1.5k–15k）进行缩放实验。
- **对比方法/模型池**：
  - 开源视频生成模型：Wan 2.1 (1.3B)、Wan 2.2 (5B)、CogVideoX (2B)。
  - LoRA 微调变体：CogVideoX 5B-LoRA、Wan 2.2 5B-LoRA。
  - 商业 API 模型：Wan 2.6、Hailuo-V2（2026 年 2 月访问）。
  - 基线提取器：Dino3DFlowIDM（作为 IDM 基线）。
- **消融与鲁棒性实验**：
  - 比较 KineBench 管线与 IDM 基线在 7 个未知任务轨迹上的位姿恢复误差。
  - 加入控制的视觉扰动：夹爪变形、20%/50% 遮挡、低对比度、运动模糊、图像噪声。
  - 深度估计消融：比较 FoundationPose + 真值深度、FoundationPose + MoGeV2 深度、以及 IDM 基线的误差。
  - 对比“训练充分”与“欠拟合”MoGeV2 深度质量对位姿误差的影响。

## 5. 实验数量与充分性

- 实验数量较为丰富：
  - 20 个多样化操作任务，跨四个评估套件；
  - 7 组以上模型（含微调变体和 API 模型）参与主流对照；
  - 与 IDM 基线的直接对比，包含轨迹误差、分布误差、受控扰动下的鲁棒性；
  - 深度估计质量消融、真值深度对照；
  - S3 中针对同一架构（Wan 2.1 1.3B）的数据量和计算步数缩放实验。
- 充分性与客观性分析：
  - 优点：显式管线使误差来源可分解、可审计，相比端到端 IDM 更公平地暴露世界模型自身缺陷；实验覆盖了多种典型泛化场景。
  - 不足：模型池中“前沿模型”主要集中于 Wan/CogVideoX 系列，缺乏更多架构类型；实验在单一模拟器（ManiSkill3）中进行，未涵盖真实世界数据；受限于 4 卡 A100 的预算，缩放实验仅在 1.3B 模型上进行，未探索更大参数量。

## 6. 主要结论与发现

- **KineBench 有效减少归因歧义**：显式运动学接地的位姿误差显著低于 IDM 基线，尤其在分布外轨迹和视觉扰动下；旋转误差的分布更集中，长尾失败更少。
- **SPARC 和可操控性指标提供互补信号**：
  - SPARC 对零样本或欠优化模型的运动流畅度敏感，能筛选出严重物理幻觉；对全参数微调模型则区分度不足（其失败更多来自语义错配）。
  - 可操控性指标能反映模型对机器人运动学边界的“内化程度”；全参数微调模型通常保持较低的可操控性成本，而零样本和容量受限的 LoRA 模型更容易产生奇异位形。
- **视觉质量不等同于物理可执行性**：例如，Wan 2.2 在 OpenBoxHard 任务上从 60.0% 掉到 30.0% 当评估资产从“训练内”变为“未见”，说明模型可能依赖表面纹理特征而非 3D 几何可操作线索。
- **缩放规律是复杂性条件化的**：
  - 简单任务（OpenBoxEasy）增加数据甚至可能降低成功率（100% → 83.33%），更多优化步数的收益有限或为负。
  - 复杂任务（StoreCube-v2）增加优化预算可将成功率从 13.34% 提升至 69.52%。
  - 整体上，数据/计算带来的边际收益随任务难度增加而递减，呈现非线性、任务依赖的缩放行为。

## 7. 优点

- **方法创新**：第一个完全消除 IDM 依赖的封闭式闭环基准，用显式几何接地解决了长期存在的归因歧义问题。
- **可解释性与可诊断性**：管线模块化，分割、深度、位姿跟踪各环节均可单独检查和消融，误差可定位到具体感知模块。
- **评估视角延拓**：首次将 SPARC 和可操控性指数引入生成式视频模型评估，从二维像素域扩展到三维机器人中心运动学域。
- **系统化基准设计**：四个套件分解出执行、迁移、视觉 OOD、缩放四条轴，能分别刻画模型的不同能力短板。
- **鲁棒性研究充分**：对视觉扰动、深度质量差异等进行了控制变量分析，验证了管线在分布偏移下的稳定性。

## 8. 不足与局限

- **依赖感知模块质量**：位姿估计仍然依赖于分割、深度恢复和末端执行器的可见性；深度回归误差（约 1.5–3 cm）是平移误差的主要来源。
- **旋转误差仍较大**：MoGeV2 管线剩余旋转误差约 10°，对精密操作评估有潜在影响。
- **训练数据来源单一**：专家轨迹由运动规划生成，未包含人类遥操作数据，动作分布与真实人类演示存在差异。
- **评估范围有限**：仅在 ManiSkill3 模拟器中验证，未扩展到真实世界或其他模拟器；模型池和参数量规模有限。
- **部分结论是启发式的**：LoRA 与全参微调在迁移性上的差异、以及“过专业化”等解释均被作者明确标识为假设而非因果验证。
- **与现有二维指标的整合缺失**：论文未将 3D 运动学指标与 2D 像素评估（如 FVD、VBench）结合，未来工作才计划融合。
