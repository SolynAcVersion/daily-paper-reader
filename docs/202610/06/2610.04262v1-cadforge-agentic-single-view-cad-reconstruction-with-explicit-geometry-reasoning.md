## 摘要
从单视图图像重建可编辑的参数化CAD模型对现代制造业具有重要的实用价值，但由于几何观测不完整以及零件间关系复杂，该任务仍极具挑战性。为解决这一问题，我们提出CADForge，一个将单张图像逐步转换为CadQuery程序的智能体框架。CADForge将物体分解为具有CAD语义的部件，并对每个部件执行显式几何推理；该过程首先识别与CAD相关的约束，然后通过数学代码将其转化为精确的建模参数。随后，推断出的参数驱动可执行CadQuery程序的逐部件合成，并由审查智能体对生成的几何进行评估，提供有针对性的反馈以进行迭代优化。为进一步提升鲁棒性与效率，CADForge引入了失败引导的工具库构建机制，将积累的经验蒸馏为工具，并维护一个紧凑的参数化CAD记忆，以便按需检索建模上下文。在多种单部件与多部件物体上的实验表明，CADForge在重建保真度和感知质量方面持续优于现有基线，展示了一种实现精确单视图CAD重建的有效途径。

## Abstract
Reconstructing editable parametric CAD models from a single-view image is of great practical value for modern manufacturing, yet remains challenging due to incomplete geometric observations and complex inter-part relationships. To address it, we propose CADForge, an agentic framework that progressively converts a single image into CadQuery programs. CADForge decomposes an object into CAD-meaningful components and performs explicit geometric reasoning for each component, a process that first identifies CAD-relevant constraints and then translates them into precise modeling parameters through mathematical code. The inferred parameters then drive component-wise synthesis of executable CadQuery programs, with a review agent evaluating the resulting geometry and providing targeted feedback for iterative refinement. To further improve robustness and efficiency, CADForge incorporates a failure-guided toolkit construction mechanism to distill accumulated experience into tools, and maintains a compact parametric CAD memory for retrieving modeling context on demand. Experiments on diverse single- and multi-part objects show that CADForge consistently outperforms existing baselines in reconstruction fidelity and perceptual quality, demonstrating an effective approach to accurate single-view CAD reconstruction.

- **研究动机**：参数化 CAD 模型相比点云与网格，能提供精确的 B-Rep 边界表示与灵活可编辑性，对家具设计、工业制造等实际应用价值很高，但人工建模需要专业知识与大量手工劳动。
- **核心问题**：从**单视图图像**重建可编辑参数化 CAD 模型。该任务要求模型不仅要从不完整视觉观测中推断完整 3D 几何与结构关系，还要将其转化为精确的 CAD 建模参数与命令。
- **现有方法局限**：
  - 早期方法依赖针对图像-CAD 数据集的特定任务微调，数据集多为简单模型，在分布外图像与复杂多部件物体上易产生几何扭曲、部件缺失或断连。
  - 近期基于智能体的 3D 代码生成方法虽能产生视觉上可看的结果，但 token 成本高，且难以充分捕捉底层几何约束与部件间空间关系，导致重建不忠实。
- **整体含义**：论文提出 **CADForge**——一个免训练（training-free）的智能体框架，将单张图像逐步转换为 CadQuery 程序，验证了显式几何推理与智能体迭代对单视图 CAD 重建的有效性，为可编辑参数化建模提供新路径。

## 2. 方法论

### 2.1 核心思想

- 不做整体一次性生成，而是将物体**分解为 CAD 语义部件**，逐部件渐进构建参数化 CAD 模型。
- 每个部件先做**显式几何推理**（几何观察 + 几何编程），再合成可执行 CadQuery 代码，并通过审查智能体迭代修正。
- 通过**失败引导工具库**与**紧凑参数化 CAD 记忆**提升鲁棒性与效率。

### 2.2 问题形式化

- 给定单张 RGB 图像 I，目标是重建部件感知的参数化 CAD 模型 O = (B, Q)：
  - B = {B₁,…,B_N} 为各部件 B-Rep 形状；
  - Q = {q₁,…,q_N} 为对应 CadQuery 程序；
  - 每个程序由 CAD 内核执行：**B_i = KernelExecute(q_i)**。

### 2.3 部件分解（Component Decomposing）

- 用 VLM 将物体分解为**有序部件序列** P = [(p₁,b₁),…,(p_N,b_N)]，其中 p_i 为部件标签，b_i 为语义/结构简述。
- 分解反映实际 CAD 工作流：
  - 共享几何结构（对称、重复）的成员作为**单一建模单元**；
  - 序列按依赖关系排序：先建结构件建立几何骨架，再建依赖部件；
  - 被遮挡区域结合视觉证据与物体先验推断合理缺失部件。

### 2.4 几何推理（Geometry Reasoning）

分两阶段：

- **几何观察（Geometry Observation）**
  - 为每个部件 p_i 从已构建部件中选择紧凑参考集 R_i（依据空间关系与形状相关性）。
  - 输出 CAD 导向的规格：**g_i = Observe(I, p_i, b_i, R_i)**。
  - g_i 同时刻画：
    - 部件内层面：轮廓、主朝向、对称性、重复模式；
    - 部件间层面：相对 R_i 的位姿与尺度，以及连接、对齐、支撑关系（含平行、垂直约束与相对偏移）。

- **几何编程（Geometry Programming）**
  - 从参数化 CAD 记忆中检索参考部件结构化参数 Θ_{R_i}。
  - 合成轻量 Python 程序并执行得到目标参数：**s_i = ProgramLLM(g_i, Θ_{R_i})，θ_i = Exec(s_i)**。
  - θ_i 为结构化字典，记录参数名、含义与数值，为下游代码生成提供精确、可检查的几何指导。

### 2.5 CadQuery 代码生成

- **代码合成**：**c_i = CodeLLM(p_i, b_i, g_i, θ_i, Θ_{R_i})**，与之前程序编译成更新后的 CAD 模型。
- **修复机制**：若执行失败或未通过有效性检查，代码修复器根据错误信息修正。
- **审查机制**：成功执行后渲染两个互补视角（新部件高亮），与输入图像拼接送入 Review Agent；审查部件形状、尺度、位置，将错误归因于几何推理或代码合成，并路由回对应阶段给出针对性反馈。

- **失败引导工具库自构建**
  - 在 Fusion 360 数据集的独立 60 个案例上运行流程，记录完整生成轨迹。
  - 挖掘两类失败：反复执行失败的运行；按 Chamfer Distance 排序最差 30% 的几何不准案例。
  - LLM 分析失败模式，将易错操作封装为可复用 helper（如 `safe_union`、`strict_cut`、`sweep_tube_along_path`、`rounded_box`、`safe_fillet` 等），仅保留验证有效的工具，最终形成 **10 个工具**的工具库。
  - 代码生成时可直接调用 helper，提升可靠性并减少修复迭代。

### 2.6 参数化 CAD 记忆

- 以嵌套字典实现，每个被接受部件关联其关键建模参数：**Θ_i = {(k_j, v_j)}**。
- 更新规则：**M_i = M_{i-1} ∪ (p_i ↦ Θ_i)**。
- 每步以参考部件标签查询记忆，检索对应参数条目，避免传递完整历史造成的冗余与 token 开销。

- VLM 与 CAD-Coder 若产生不可执行程序则反复查询直至获得可执行结果，保证每个样本都有有效输出参与几何比较。
