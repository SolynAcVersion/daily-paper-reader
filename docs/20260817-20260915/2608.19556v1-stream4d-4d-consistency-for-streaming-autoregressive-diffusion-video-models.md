## 摘要
流式自回归扩散模型能够实现实时、长时程的视频生成，但其训练目标优化的是局部帧预测，而非连贯世界的几何与动态：长时间推演会累积几何漂移，并退化为静止或不自然的运动。近期的双向方法利用基于3D高斯泼溅重建构建的奖励信号来解决这一问题。然而，单一刚性3D重建无法建模动态场景，因此这种评判器会将真实的物体运动作为重建误差加以惩罚，并通过冻结视频来最大化奖励。这种捷径在自回归设定下尤其有害，因为每个片段都可能传播已经静止的配置。在这项工作中，我们提出Stream4D，它用前馈4D重建奖励替代静态评判器，显式建模场景动态，使连贯运动能够获得高一致性奖励。为了进一步引导运动幅度和质量，我们加入运动先验，奖励自然的场景流幅度，同时惩罚抖动和非刚性伪影。我们的最终方案将这两项与轻量级感知锚点相结合。在各种自回归视频主干网络和不同生成时程上，Stream4D提升了4D重建质量，更有效地保持运动，并获得更高的人类对齐偏好。项目页面：https://banyuanhao.github.io/Stream4D/

## Abstract
Streaming autoregressive diffusion models enable real-time, long-horizon video generation, but their training objectives optimize local frame prediction rather than the geometry and dynamics of a coherent world: long rollouts accumulate geometric drift and degrade into static or unnatural motion. Recent bidirectional approaches address this problem using rewards signals built upon 3D Gaussian-Splatting reconstruction. However, a single rigid 3d reconstruction cannot model a dynamic scene, so this critic penalizes genuine object motion as reconstruction error and is maximized by freezing the video. This shortcut is especially detrimental in the AR setting, where each chunk can propagate an already-static configuration. In this work, we propose Stream4D, which replaces the static critic with a feed-forward 4D reconstruction reward that explicitly models scene dynamics, allowing coherent motion to receive high consistency rewards. To further guide motion magnitude and quality, we add a motion prior that rewards natural scene-flow magnitude while penalizing jitter and non-rigid artifacts. Our final recipe combines these two terms with a lightweight perceptual anchor. Across various autoregressive video backbones and various generation horizons, Stream4D improves 4D reconstruction quality, preserves motion more effectively, and achieves higher human-aligned preference. ## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：流式自回归（AR）扩散视频模型按 chunk 逐块生成，配合少步蒸馏骨干（Wan2.1 等）可实现实时、长时程视频生成，面向具身智能体、模拟器与交互式应用。
- **核心问题**：现有 AR 训练目标只优化**局部帧预测**，并不显式约束"世界的几何与动态"是否连贯。长 rollout 会累积误差，出现尺度漂移、深度关系不一致、物体/相机运动不合理，最终退化为**静止画面或不自然运动**。
- **已有做法的缺陷**：World-R1、VideoGPA 等 RL 方法用**静态 3D 高斯泼溅（3D-GS）重建**构造奖励。但单一刚性 3D 重建无法建模动态场景，**真实物体运动会被当作重建误差而受惩罚**，奖励的最大化路径就是"冻结场景、只允许相机运动"——这是一种 reward hacking 捷径。
- **AR 场景下更严重**：AR 模型只能看到已生成帧，时间上下文更少；一旦早期 chunk 被压成静止，后续 chunk 会持续传播同一刚性配置，且仍能获得高重建奖励。
- **论文含义**：作者将问题重新表述为"**从 3D 一致性走向 4D 一致性**"，把几何奖励设计从静态重建器换成前馈 4D 重建器，使"连贯运动"而非"静止"成为高奖励解。

## 2. 方法论

### 2.1 核心思想
- 用**前馈 4D 高斯泼溅（MoVieS）**对候选 rollout 做动态场景重建并重渲染，以重渲染与原始帧的感知一致性作为 4D 一致性分数。
- 叠加一个**峰值高斯运动门 + 质量因子**的运动先验，引导运动幅度落在"自然区间"，同时抑制抖动与非刚性伪影。
- 再加一个**轻量感知锚点（HPSv2）**防止外观保真度退化。
- 三条奖励轴各自 z-normalize 后加权求和，用**前向过程 DiffusionNFT** 损失做策略优化。

### 2.2 关键技术细节
- **基础框架**：沿用 Astrolabe（rolling KV-cache 生成 + DiffusionNFT 前向过程更新），在冻结的 4 步蒸馏骨干上训练 LoRA。
- **DiffusionNFT 正负速度构造**：
  - `v+ = (1-β)·v_θold + β·v_θ`
  - `v- = (1+β)·v_θold - β·v_θ`
  - 损失 `L_policy = r̃·||v+ - v_target||² + (1-r̃)·||v- - v_target||²`
- **4D 重建流水线**：先用 **StreamVGGT** 估计逐帧相机位姿与内参（26 帧线性子采样，294×518），再送入 **MoVieS**，得到 (i) 规范高斯点云 G_can、(ii) 逐帧高斯属性覆盖 A_t、(iii) 逐帧场景流偏移 Δ_t，并在估计相机 C_t 下重渲染。
- **奖励一：4D-GS 重建一致性 R_recon**
  - `R_recon = clip(1 - (1/T)Σ_t LPIPS(W̃_t, W_t), 0, 1)`
  - 用 LPIPS（AlexNet）而非像素误差，对低层错位不敏感，但对几何漂移、身份漂移、无法组织成稳定动态场景的运动敏感。
- **奖励二：门控运动联合项 R_mot = g(m) · smooth · rigid**
  - 运动幅度 `m`：由 MoVieS 运动场 P 与置信图 conf 计算逐像素 3D 场景流速度 `v_t = P_{t+1} - P_t`，取动态掩码 D（最快的 20% 像素-时间条目）上的置信加权均值。
  - 运动门 `g(m) = exp(-(m - m_nat)²/(2σ²))`，`m_nat = 0.020`（base rollout 的中位数），`σ = 0.010`。峰值形态**同时惩罚静止塌缩与失控模糊**。
  - 平滑项 `smooth = exp(-mean_D||v_{t+1} - v_t|| / (m + c))`，惩罚过度聚合运动与形变（c = 1e-4）。
  - 刚性项 `rigid = exp(-(k_rough/2)(mean_D||∇_x v_t|| + mean_D||∇_y v_t||))`，`k_rough = 400`，惩罚空间上剧烈不一致的场景流（撕裂、抖动、融化），但允许平滑的非刚性/铰接运动。
- **奖励三：感知锚点 R_hpsv2**：用 HPSv2 直接对生成帧打美学分，约束几何与动态之外的逐帧外观。
- **奖励集成与优势**：
  - `R = w_recon·z̃[R_recon] + w_mot·z̃[R_mot] + w_hpsv2·z̃[R_hpsv2]`
  - 权重：Self-Forcing (1.0, 1.0, 0.3)；Causal-Forcing (1.0, 0.5, 0.6)；LongLive (0.8, 1.0, 0.6)。
  - 组中心优势 `A = R - mean_group R`，`r̃ = clip(A/A_max, -1, 1)/2 + 1/2`，`A_max = 5`。
- **算法流程**（Algorithm 1 概要）：① 以 sink 帧 + 滚动窗口构成上下文，为每个 prompt 采样 G 个候选 rollout，更新 KV cache；② 对每个 rollout 跑一次 StreamVGGT+MoVieS 前向（重建与运动两轴**共享同一前向缓存**），计算三轴奖励与组优势；③ 回放每个窗口，用 rollout 级优势做窗口局部 NFT 更新，并叠加选择性 KL 惩罚（基于排序不一致的高不确定性掩码）；④ EMA 更新 old policy，KL 漂移超阈值时重置 reference policy。

## 6. 主要结论与发现

- **4D 一致性提升可

以显著提升 rollout 稳定性**：在三个蒸馏 AR 骨干上，Stream4D 在 MoVieS Recon、4DGT Recon、LLM judge 与 VideoReward 四组指标上普遍优于 World-R1 / VideoGPA 与 base，尤其在长时程（LongLive 165 帧 / 10.3s）上优势最明显，说明 4D 一致性奖励能有效抑制"尺度漂移 → 静止塌缩"的退化链条。

- **静态重建奖励确实存在 reward hacking**：World-R1 / VideoGPA 在"冻结类"指标上看似占优，但在**要求保留运动的 LLM judge 一致性判定**与 VideoReward 的 Motion 分项上明显落后；一旦把"是否保留运动"作为一致性门槛，其"高一致性"优势随即消失，直接印证了论文对静态 3D-GS 奖励的分析。

- **重建器无关性得到验证**：主结果用 MoVieS，交叉验证用架构/权重/数据均不同的 **4DGT**，两套重建器下方法排序一致，说明收益来自"4D 一致性"这一目标本身，而非对某个特定重建器的过拟合。

- **门控运动项是核心增益来源**：消融显示，仅加重建项即可改善几何稳定性，但会偏向"少动"；加入峰值高斯运动门后，Motion 指标与人类偏好同步上升；移除门（无门/线性项）会重新滑向静止或失控模糊。门目标 `m_nat` 在 0.010–0.030 区间内结果稳定，0.020 附近最优。

- **三条奖励轴互补、缺一不可**：去掉 HPSv2 锚点会带来外观/细节退化；去掉重建项则几何漂移回归；去掉运动项则运动幅度塌缩。三者组合在"运动幅度—重建质量"权衡平面上把解推向了更接近自然动态的帕累托区域（Figure 3）。

- **人类盲测支持自动指标**：2AFC 盲测中，评分者对 Stream4D 的偏好显著高于 base 与两个 RL 基线，且偏好方向与 LLM judge / VideoReward 的趋势一致，降低了"纯指标优化"的疑虑。

## 7. 优点与亮点

- **问题重构清晰且击中要害**：把"3D 一致性"升级为"4D 一致性"，并明确指出静态重建器下的最优策略是"冻结场景"，是对现有 RL-for-video 奖励设计的准确诊断，而非简单的指标堆叠。

- **奖励设计与被优化目标对齐**：运动门、平滑项、刚性项分别对应"幅度—时间连续性—空间连续性"三个可解释维度，且都以可微/可计算的前馈 4D 重建为底座，工程上自洽。

- **成本控制巧妙**：重建与运动两轴共享同一次 StreamVGGT + MoVieS 前向，使额外奖励轴的边际算力开销可忽略，7 秒/rollout 的量级在 RL 训练中可接受。

- **评测严谨度较高**：跨 3 个骨干、2 种时域、4 类指标；用第二个 4D 重建器做重建器无关交叉验证；LLM judge 做顺序去偏 + 多次复跑；一致性判定显式要求保留运动；人类盲测含注意力检查题；附录用随机 prompt 子集做稳健性补强。

## 8. 局限与不足

- **依赖外部重建器的质量与鲁棒性**：奖励信号的上限受 StreamVGGT 位姿估计与 MoVieS 4D 重建精度约束；在剧烈遮挡、快速相机运动或强非刚性形变场景下，重建误差可能被误判为"不连贯运动"，从而给出错误奖励。

- **基线为作者自行复现**：World-R1 / VideoGPA 无面向蒸馏-AR 的公开 checkpoint，复现细节（超参、奖励权重、训练步数）会影响对比结论强度，尽管作者统一了 base、trainer 与 prompt 数据。

- **主评测偏向运动显著场景**：主表使用 motion-prominent 子集，虽符合论文"运动保持"的核心主张，但天然利于本方法的设计假设；随机子集补强缓解而非消除这一偏差。

- **`m_nat` 等超参的先验依赖**：运动门峰值由 base rollout 中位数标定，隐含"自然运动幅度"这一假设；当目标领域（如慢速室内、显微、卫星）的自然运动尺度与 VidProM 分布差异较大时，门的位置可能需要重新标定。

- **算力门槛较高**：每骨干约 600–800 GPU-hours 的 LoRA 微调，加上每 rollout 一次 4D 重建前向，使方法在资源受限场景下复现成本偏高；论文亦未给出总墙钟时间与推理时延的完整分解。

- **未覆盖音频/文本条件与多模态一致性**：当前 4D 一致性仅约束视觉几何与动态，未涉及音画同步、语义—动态一致性等长视频生成的其他关键维度。

## 9. 对领域的启示与未来方向

- **奖励设计应从"重建器"走向"动态重建器"**：静态 3D 重建奖励的最优解天然是静止，任何以几何一致性为核心奖励的视频生成 RL 都应警惕这一捷径；4D 重建提供了更贴合视频本质的奖励底座。

- **"门控式"奖励形态值得推广**：峰值形态的奖励（而非单调奖励）能同时惩罚"不动"与"乱动"，这一思路可迁移到视频生成长度、运动速度、镜头切换频率等维度。

- **未来可探索**：更轻量的在线 4D 重建器（降低 7 秒/rollout 开销）；把 4D 一致性扩展到语义/物理约束（如接触、刚体守恒）；将 4D 一致性用于闭环具身智能体的世界模型训练；以及探索在非蒸馏全扩散模型上的适用性。
