## 摘要
世界模型可以在不学习稳定保持的动力学的情况下预测视频。我们测试了仅在钟摆视频上训练的冻结DreamerV3是否学习到一个标量，其自身的潜在转移将其视为近似守恒量。无标签搜索在独立训练的保守模型中恢复了相同的类能量不变量，而相同的过程在匹配的阻尼模型中未发现可比的不变量。在自主推演期间，该量会发生漂移。将潜在状态投影回其初始水平集可降低所有三个保守模型中的推演误差，而匹配的随机约束通常会增加误差。这些结果将动态意义的不变量与仅可解码的相关量区分开来，并揭示了一个具体的失效模式：世界模型可以从像素中学习物理约束，但在向前想象时却违反该约束。

## Abstract
World models can predict video without learning dynamics that they reliably preserve. We test whether a frozen DreamerV3 trained only on pendulum video learns a scalar that its own latent transition treats as approximately conserved. A label-free search recovers the same energy-like invariant across independently trained conservative models, while the same procedure finds no comparable invariant in matched damped models. During autonomous rollouts, this quantity drifts. Projecting the latent state back toward its initial level set reduces rollout error in all three conservative models, whereas matched random constraints usually increase it. These results distinguish a dynamically meaningful invariant from a merely decodable correlate and reveal a concrete failure mode: a world model can learn a physical constraint from pixels yet violate that constraint when it imagines forward.

- **研究动机**：世界模型（World Model）能够预测未来视频，但**良好的视频预测能力并不等于学到了真实的物理动力学**。一个世界模型可能在像素层面上学会了产生看似合理的未来帧，却并未在潜空间中稳定地保持物理约束（如能量守恒）。传统做法通过探针（probe）从隐状态中解码物理量，但探针精度只说明信息“可解码”，不能说明模型的转移过程“真正使用”这些信息。
- **核心问题**：一个仅靠钟摆视频训练出的 DreamerV3 世界模型，是否在其**自身的潜转移**中学习到了一个近似守恒的物理不变量？如果在自主想象（rollout）过程中这个不变量发生漂移，那么纠正这种漂移是否能够降低预测误差？
- **整体含义**：论文揭示了一种具体且重要的失败模式——**世界模型可以从像素中学习到物理约束，但在自主前向想象时却违反这一约束**。这动摇了“预测得好＝学到了动力学”的常见假设，对于基于世界模型的规划、控制与可靠部署具有警示意义。

## 2. 方法论

- **核心思想**：在冻结的 DreamerV3 世界模型潜空间中，通过无标签搜索寻找一个近似守恒的标量函数 `C(z)`，然后利用该标量的水平集约束去修正自主展开时的潜在状态，以验证该不变量是否具有动态因果意义。
- **模型与潜坐标**：
  - 使用 DreamerV3（13.5M 参数，32×32 分类随机潜变量），只训练世界模型，无 actor/critic。
  - 将确定性循环状态 `h` 减去均值后投影到前 12 个主成分方向上，得到低维坐标 `z = Pᵀ(h - h̄)`。
  - 用模型自身的一步转移位移 `F(z) = Pᵀ(T(h)-h)` 来刻画潜流，避免拟合额外向量场。
- **候选函数族**：在 12 维坐标上构造**最高 4 次的 1819 个单项式基**（去掉常数项），候选不变量为 `C(z) = aᵀφ(z)`。
- **不变量评分**：使用 RayLeigh 商
  `ratio(C) = 轨迹内方差 / 总方差`，
  最小化该比值得到最守恒的标量。它通过广义特征值问题 `W a = λ T a` 求解，一次分解即可得到完整排序。
- **流对齐（Flow Alignment）**：单纯守恒无法唯一确定标量（E 和 E² 都守恒）。为了进一步筛选，联合拟合一个反对称矩阵 `B`，满足 `F ≈ B∇C, Bᵀ = -B`。这模仿哈密顿力学中守恒量与流的关系，能够区分 E 与 E² 等。
- **干预方法（水平集投影）**：在自主想象每一步，将潜在状态向初始水平集投影：
  `z ← z - α [C(z) - C₀] ∇C(z) / ‖∇C(z)‖²`，
  其中 `C₀` 是第一步编码状态的值。该修正不重训模型、不修改解码器。
- **对照关键**：
  - 六组随机初始化的 DreamerV3 作为未训练对照，证明能量相关解码并非训练所独有。
  - 匹配的阻尼摆（damped pendulum）训练模型作为消融，检验搜索算法是否只是“总能找到看起来守恒的标量”。
  - 随机多项式约束作为干预对照，验证修正效果是否特异性属于恢复出的不变量。

## 6. 主要结论与发现

- 三个训练的保守 DreamerV3 模型均恢复了与能量高度相关的潜不变量（|ρ_E| = 0.967–0.975），且该标量在观测条件轨迹上几乎不漂移（轨迹内方差约占总方差 1.1e-4）。
- **训练的关键作用是“复现性”**：未训练模型虽然也能出现高达 0.908 的能量相关读数，但彼此之间差异极大（0.17–0.91），而训练后的三个模型高度一致（0.967–0.975）。
- 阻尼模型中，相同提取流程无法找到可比的守恒标量（漂移量增加约 2400 倍，保持外不变量比率从 0.0027–0.0121 变为 0.983–0.994），且无重叠区间。说明该搜索不是“总是能找出守恒产物”。
- 在自主想象中，恢复的不变量会漂移。通过水平集投影纠正这种漂移，**在全部三个保守模型上降低了 50 步 rollout 误差**（2.9%–3.3%–3.5%）；而匹配随机约束的误差通常大幅增加（中位 +53.9%，60 次中 53 次变差），且两种干预差异在 3 个模型中有 2 个统计上特异性明显（1 个模型有 3/20 个随机约束斜率更优）。
- 修正作用并非集中在高方差方向，而是倾向于沿着高“损伤敏感度”方向作用（敏感性与修正强度正相关，与方差相反），暗示该不变量指向了动力学关键流形。
- **总结论**：DreamerV3 从像素中学到了一个能量型不变量，但自身的前向想象力未能可靠地保持它；纠正这一违反可以改善预测。这暴露了“学得物理结构”和“在推演中尊重结构”之间的鸿沟。
